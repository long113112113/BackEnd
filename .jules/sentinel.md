## 2024-05-26 - Unhandled Exception (DoS) when parsing HMAC via Buffer.from
**Vulnerability:** In `src/services/mqtt.handler.js`, the code previously passed `receivedHmac` directly to `Buffer.from(receivedHmac, 'hex')` without any type validation. While the previous double-hashing step ensured that `timingSafeEqual` never received mismatched buffer lengths, it failed to handle the case where `receivedHmac` was not a string. If an attacker sent a malformed payload where `hmac` was an object or other unexpected type, `Buffer.from` could throw a `TypeError`, crashing the Node process and causing a Denial of Service.
**Learning:** `Buffer.from(input, 'hex')` requires the input to be a string. Furthermore, validating the format (e.g. hex string) and length of cryptographic parameters ensures that downstream operations behave predictably.
**Prevention:** Always perform type checking (`typeof input === 'string'`) and format validation (e.g., regex `^[0-9a-fA-F]+$`) on external payloads before attempting to parse them into `Buffer`s.
